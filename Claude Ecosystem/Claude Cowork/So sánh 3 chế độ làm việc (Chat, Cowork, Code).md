# So sánh 3 chế độ làm việc (Chat, Cowork, Code)

Claude Desktop App có 3 chế độ làm việc chính, mỗi chế độ phù hợp một dạng công việc khác nhau.

## Bảng phân biệt

| Tiêu chí | Chat | Cowork | Code |
| --- | --- | --- | --- |
| Bản chất | Thinking with Claude | Delegating to Claude | Building software with Claude |
| Hình thức | Hội thoại luân phiên (turn-by-turn) | Không gian làm việc đa công cụ (workspace) | Môi trường lập trình (agentic coding tool) |
| Phù hợp nhất | Đặt câu hỏi/khám phá ý tưởng; viết nháp để tự gọt dũa; tác vụ xong trong 1 câu trả lời | Việc đa bước qua nhiều file/tool; tạo tệp sản phẩm thực tế (doc/sheet/deck); giao việc rồi quay lại nhận kết quả | Làm việc trực tiếp trong repo; tối ưu/sửa lỗi nhiều file code; dùng terminal/git/tests |

**Triết lý ghi nhớ:** Chat để *suy nghĩ* cùng AI — Cowork để *ủy quyền* công việc — Code để *viết phần mềm* cùng AI.

## Bài tập tình huống

### Task 1/6

- **Yêu cầu:** đọc 5 file PDF nhà cung cấp trong Downloads, so sánh giá & SLA, xuất kết quả ra spreadsheet.
- **Đáp án:** Cowork.
- **Lý do:** cần đọc file thật trên ổ đĩa, xử lý đa bước (đọc → phân tích → so sánh), tạo ra sản phẩm thực tế (spreadsheet) — không phải lập trình (Code) hay chỉ trao đổi thông tin (Chat).
