# Chuyển dịch tư duy: Chat → Cowork

- **Thói quen cũ (Chat, lặp từng bước):** gõ câu hỏi → nhận trả lời → gõ câu hỏi tiếp → tự ghép các bước lại.
- **Tư duy mới (Cowork, ủy quyền trọn gói):** giao toàn bộ một khối việc thực tế (thu thập bối cảnh, phân tích, tạo file, dùng tool) → Claude tự thực hiện → nhận sản phẩm hoàn chỉnh.

> **Quy tắc chọn:** dùng **Chat** cho việc muốn *hỏi hoặc suy nghĩ cùng* AI; dùng **Cowork** cho việc *mà bình thường chính bạn phải tự tay làm*.

## So sánh Claude Chat vs Claude Cowork

| Tiêu chí | Claude Chat | Claude Cowork |
| --- | --- | --- |
| Cơ chế | Luân phiên từng lượt (turn-by-turn) | Chạy kế hoạch đa bước tự động |
| Xử lý dữ liệu | Phân tích file tải lên rời rạc | Đọc/ghi trực tiếp thư mục local & kết nối nhiều app cùng lúc |
| Mục đích | Trả lời câu hỏi, hội thoại, viết nháp | Ủy quyền xử lý toàn bộ quy trình công việc, ra kết quả end-to-end |
| Đầu ra | Đoạn văn bản/code phản hồi | Sản phẩm hoàn chỉnh (file, báo cáo, project) lưu vào thư mục local |
| Môi trường | Trong khung chat | Local, cloud app, trình duyệt |
