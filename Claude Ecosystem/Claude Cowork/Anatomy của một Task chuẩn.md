# Anatomy của một Task chuẩn

Ví dụ prompt chuẩn dành cho Cowork:

> *"Quý trước chúng ta đã quyết định gì về bảng giá? Tra cứu qua biên bản họp trong thư mục Q3 Sales, email từ đội sales, kênh Slack ban lãnh đạo, và slide đề xuất — tổng hợp lại và viết bản tóm tắt 1 trang để gửi đội lãnh đạo."*

## Vì sao là task chuẩn cho Cowork

1. **Context-gathering đa nguồn** — quét nhiều kênh dữ liệu khác nhau (folder máy tính, email, Slack, slide).
2. **Kế hoạch đa bước** — đọc → lọc dữ liệu → phân tích → tổng hợp.
3. **Artifact rõ ràng** — ra một file tóm tắt cụ thể, gửi đi ngay được.
