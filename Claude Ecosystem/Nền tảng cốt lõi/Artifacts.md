# Artifacts (Đầu ra)

Khu vực hiển thị và xuất bản **kết quả đầu ra** (code, tài liệu, trang web, sơ đồ, dashboard...) tách biệt khỏi luồng hội thoại chat.

- Cho phép xem, chỉnh sửa và cập nhật lại đầu ra mà không làm loãng cuộc trò chuyện.
- Có thể xuất bản (publish) thành link riêng để chia sẻ với người khác.
- Hỗ trợ nhiều định dạng: HTML, Markdown, sơ đồ Mermaid, React component, v.v.
