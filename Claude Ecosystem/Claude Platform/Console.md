# Console (Trang quản trị)

Bảng điều khiển trên web dùng để quản lý việc dùng Claude Platform ở mức tài khoản/tổ chức.

- Tạo và quản lý **API keys**.
- Theo dõi lượng tiêu thụ token và chi phí.
- Thử nghiệm prompt (prompt engineering) trực tiếp trên giao diện, không cần viết code.
- Quản lý các agent tự động đã triển khai.
